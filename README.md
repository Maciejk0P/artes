# artes

Claude Code skills I build and use. Each skill lives in its own folder with its own README and
tests.

## Skills

- [claude-health-check](claude-health-check/README.md): a health check for a Claude Code setup
  (memory files, rules, skills, commands, agents, hooks, settings) that reports what it found and
  applies only the changes you confirm.
